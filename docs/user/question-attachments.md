# Files in question answers

When an agent asks a question you can answer in your own words, use **Attach files** or paste an image into the answer field. You can send a file by itself, with a selected option, or with a typed answer.

Each question keeps its own answer and attachments as you move between questions, leave the chat, or reload. Your normal prompt draft stays separate. Wait for uploads to finish before submitting; retry or remove any failed upload. A failed response keeps the draft available to try again.

The files go into the chat's sandbox with your answer, which tells the agent where they are. Questions that only accept predefined choices do not offer attachments.

Submitted attachments remain in the chat history; deleting the chat uses the same file cleanup as other attachments. You can attach up to 100 files across one set of answers, using the same file and total image size limits as the normal composer.
